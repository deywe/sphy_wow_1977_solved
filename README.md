## 🛠️ Installation & Setup

### 1. Clone the Repository
```bash
git clone [https://github.com/dywokb-hash/sphy_wow_proof.git](https://github.com/dywokb-hash/sphy_wow_proof.git)
cd sphy_wow_proof

```

### 2. Install Dependencies

Ensure you have Python 3.10+ installed. Install the technical stack via `pip`:

```bash
pip install -r requirements.txt

```

### 3. Run the Local 3D Viewer

Download the `wow_antigravity_audit.parquet` file from the Live App, place it in the root directory of this project, and execute:

```bash
python wow_mesh_dynamic_viewer.py

```
